# StageTracks

Multitrack backing tracks for live shows on a Mac. Jump between the parts of a song by voice, key, MIDI pad or phone; every jump lands on the beat.

- **Website and download:** https://the13thmoose.github.io/Stagetracks/ (English and Norwegian)
- **Latest version:** see [Releases](https://github.com/The13ThMoose/Stagetracks/releases/latest). Free beta for Apple Silicon Macs, macOS 14 or later. The app is not notarised yet, so macOS asks you to allow it once (the website explains how).
- **Problems:** [open an issue](https://github.com/The13ThMoose/Stagetracks/issues).

This repository holds the download website and the releases. Made by Meltveit Lydproduksjon.
